Strangely True History

Strangely True History is a short-video channel about the strangest true things from history, on YouTube, TikTok and Instagram.

Strangely True Stats is the channel's private tool for reading its own statistics (views, watch time, subscribers) so its owner can see which videos work. It is not a public service: there are no accounts or sign-ups, and the only user is the channel's owner.

  • It reads the channel's own statistics, read-only, with the owner's consent.
  • It runs on the owner's own computer, and the data is never shared.
