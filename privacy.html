Privacy policy

Last updated: 15 November 2026

Strangely True Stats is a private tool used by a single person, the owner of the Strangely True History channel, on their own computer. It publishes the owner's own videos to the owner's own YouTube channel and reads that channel's statistics. This policy describes how it handles Google user data.

Publishing to YouTube

With the owner's explicit consent through Google's sign-in screen (the youtube.upload scope), Strangely True Stats uses the YouTube Data API to:

  • upload the owner's own finished videos to the owner's own channel (videos.insert), with their title, description, tags, privacy status, scheduled release time and altered-or-synthetic-content declaration;
  • set the custom thumbnail of those videos (thumbnails.set).

It never uploads to, changes or deletes anything on any other channel, and it does not change or delete existing videos.

Statistics read

With the same kind of consent, Strangely True Stats reads, read-only:

  • YouTube Data API: the owner's own channel and its videos (titles, publish dates, view, like and comment counts).
  • YouTube Analytics API: the owner's own channel analytics (views, watch time, average view duration, subscribers gained and lost).

With the same consent through TikTok's sign-in screen, it reads the owner's own TikTok account, read-only: profile statistics (followers, likes, video count) and the owner's public videos with their view, like, comment and share counts.

It does not access any other account or user, and it collects no data about viewers.

How the data is used

The data is used only to publish the owner's own videos and to show the owner how they perform. It is processed and stored only on the owner's own computer.

Sharing

Google and TikTok user data is not sold, shared with, or transferred to any third party, is not used for advertising, and is not used to train AI models.

Strangely True Stats' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Its use of YouTube API Services is subject to the YouTube Terms of Service and the Google Privacy Policy.

Storage, retention and deletion

The only Google data kept is the sign-in token, the ID, link and status of each uploaded video, and the statistics read. All of it is kept in local files on the owner's computer, never on a server, and is deleted when the owner deletes those files or revokes access. Statistics are refreshed, and old copies replaced, on each read.

Access can be revoked at any time at myaccount.google.com/permissions; the stored token then stops working, and the owner deletes it from the computer.
